Codename Engine es un motor multiplataforma para Friday Night Funkin' diseñado para simplificar la creación de mods, centrándose en la programación flexible, además de ofrecer extensibilidad y facilidad de uso.

Es el sucesor oficial del anteriormente conocido Yoshi Engine.

## El motor utiliza <font color="yellow">HaxeFlixel</font> y cuenta principalmente con:

- Un sistema de scripting completo con una bifurcación optimizada de Hscript (llamada Hscript Improved).

- Utiliza bifurcaciones de bibliotecas populares adaptadas específicamente para el motor con el objetivo de lograr una mejor optimización.

- El sistema de modding y el softcoding son tan potentes como la programación desde el código fuente.

- Se centra en gran medida en la optimización y anima a sus usuarios a adoptar también prácticas de optimización.

- Numerosas herramientas de modding sin alterar la mecánica de juego principal ni la base sobre la que se modifica.

- Permite la modularidad mediante complementos y mods que se aplican sobre el mod principal.
  Editores avanzados que permiten una experiencia posiblemente mejor y mayor facilidad a la hora de crear el mod.
