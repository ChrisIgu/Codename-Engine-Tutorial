# 📦 ¿Qué es una `var`?

Es un contenedor, Le pones un nombre y guarda un valor (un número, un texto, un personaje).

`var nombredelavariable:Float = cantidad;`

#### **Por Ejemplo:** 
- `var personas:Int = 10;` (Con Int guardas números enteros en la variable).
- `var ganancias:Float = 122.04;` (Con Float guardas números decimales en la variable).
- `var nombre:String = "Gonzales";` (Con String puedes guardar palabras, siempre dentro de comillas).

###### siempre puedes utilizar el comando trace() para imprimir tu variable en la consola ( La consola se abre con F2), utilizando las variables antes dichas usando trace se deberían de ver así en la consola, si no sabes donde poner estos comandos no te preocupes, ya lo veremos mas adelante, por ahora céntrate en aprender como funcionan.

- `trace(personas);` en la consola debería salir el numero 10.
- `trace(ganancias);` en la consola debería salir el numero 122.04.
- `trace(nombre);` en la consola debería salir la palabra Gonzales.

o si quieres imprimir mas de una sola variable en un trace.

- `trace("esta cantidad de personas: " + personas + " tuvieron en total esta cantidad de ganancias: " + ganancias );

###### siempre separándolos con un `+`.
---

en caso de querer guardar mas de un valor en una variable puedes usar los ***Array*** o ***Listas***.

#### **Por Ejemplo:** 

```
var nombresdetrabajadores:Array<String> = ["Fabian", "Ricardo", "Pepsiman"];
var horas:Array<Int> = [12, 6, 9];
```

para agarrar un objeto dentro de un listado tienes que llamar a la variable junto con un corchete.

`` nombresdetrabajadores[];

dentro del corchete deben poner el numero en el que esta posicionado el objeto en el listado ( el primer objeto siempre es el 0);
##### por ejemplo:

- imprimir ``trace(nombresdetrabajadores[0]);`` daría como resultado en la consola "Fabian".
- imprimir ``trace(nombresdetrabajadores[1]);`` daría como resultado en la consola "Ricardo".
- imprimir ``trace(nombresdetrabajadores[2]);`` daría como resultado en la consola "Pepsiman".

y usando ambos listados puedes hacer.

``trace(nombresdetrabajadores[2] + " trabajo un total de: " + horas[1] + " horas");

esto imprimiría en la consola: ``Pepsiman trabajo un total de: 6 horas``
