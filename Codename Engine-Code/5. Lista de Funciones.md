
# 🟢 Todos los States/Substates

- **`preCreate()`, `create()`, `postCreate()`**: El nacimiento del script. Se usan para cargar personajes, fondos o variables antes, durante y después de que la pantalla aparezca.
- **`preUpdate()`, `update()`, `postUpdate()`**: El corazón. Se ejecutan cada frame (60 o más veces por segundo). Sirven para mover cosas o detectar teclas.
- **`stepHit()`, `beatHit()`, `measureHit()`**: El ritmo. Se activan en cada paso, cada pulso (beat) o cada compás de la música. Ideales para bailes o efectos visuales rítmicos.
- **`onFocus()`, `onFocusLost()`**: Se activan cuando el jugador vuelve al juego o cuando se sale a otra ventana (alt-tab).
- **`draw()`, `postDraw()`**: Controlan el renderizado. Sirven para dibujar cosas personalizadas en la pantalla.
- **`onStateSwitch()`, `onOpenSubState()`**: Cuando el juego cambia de un state a otro o abre un menú encima (como el de pausa).
- **`onResize()`**: Se activa si el jugador cambia el tamaño de la ventana.
- **`destroy()`**: La limpieza. Se usa para liberar memoria cuando cierras el estado.

# 🎤 PlayState.hx (Durante la canción)

Aquí es donde ocurre el gameplay.

- **`onStageXMLParsed()`, `onStageNodeParsed()`**: Cuando el motor lee el archivo XML de tu escenario.
- **`onPreGenerateStrums()`, `onPostGenerateStrums()`**: Cuando se crean las flechas donde aterrizan las notas (strums).
- **`onStrumCreation()`, `onPostStrumCreation()`**: Específicamente cuando nace cada flecha individual.
- **`onNoteCreation()`, `onPostNoteCreation()`**: Cuando aparecen las notas que el jugador debe presionar.
- **`onStartCountdown()`, `onPostStartCountdown()`**: El "3, 2, 1, GO!".
- **`onCountdown()`, `onPostCountdown()`**: Se activa en cada número del conteo inicial.
- **`onSongStart()`, `onStartSong()`, `onSongEnd()`**: El inicio real de la música y su final.
- **`onInputUpdate()`, `onPostInputUpdate()`**: Detecta cuando el jugador presiona teclas.
- **`onRatingUpdate()`**: Cuando cambia tu puntaje o precisión (Sick, Good, Bad, etc.).
- **`onPlayerHit()`, `onDadHit()`, `onNoteHit()`**: Cuando alguien (tú o el rival) le da a una nota con éxito.
- **`onPlayerMiss()`**: Cuando el jugador falla una nota.
- **`onCameraMove()`**: Cuando la cámara cambia de objetivo (de BF a Dad, por ejemplo).
- **`onEvent()`**: Cuando ocurre un evento programado en el Chart.
- **`onSubstateOpen()`, `onSubstateClose()`**: Pausa o menús internos.
- **`onGamePause()`**: Al presionar pausa.
- **`onGameOver()`, `onPostGameOver()`**: Cuando mueres y aparece la pantalla de derrota.
- **`onVocalsResync()`**: Cuando el motor intenta sincronizar de nuevo las voces con la música.

# 🎭 Character Scripts (Personajes)

- **`onCharacterXMLParsed()`, `onCharacterNodeParsed()`**: Al cargar la configuración del personaje.
- **`onDance()`**: Cuando el personaje hace su animación de espera (idle).
- **`onPlaySingAnim()`**: Cuando el personaje canta una nota.
- **`onPlayAnim()`**: Cuando el personaje ejecuta cualquier animación.
- **`onGetCamPos()`**: Define dónde se debe poner la cámara cuando este personaje canta.

# 💬 Dialogue Scripts (Diálogos y Cajas)

- **`structureLoaded()`**: Cuando el sistema de diálogo ya leyó el archivo de texto.
- **`next()`, `postNext()`**: Cuando pasas a la siguiente línea de diálogo.
- **`close()`**: Al terminar la charla.
- **`show()`, `hide()` / `postShow()`, `postHide()`**: Animaciones de aparición y desaparición de los personajes de diálogo.
- **`playBubbleAnim()`**: Animación de la burbuja de texto.
- **`resetText()`, `startText()`**: Cuando el texto empieza a escribirse letra por letra.

# 🌐 Global Scripts (Afectan a todo el juego)

- **`focusLost()`, `focusGained()`**: Igual que en states, pero a nivel global.
- **`preGameStart()`, `postGameStart()`**: Antes de que el juego cargue su primera pantalla.
- **`preStateSwitch()`, `postStateSwitch()`**: Se activan siempre que cambies de cualquier pantalla a otra.

# 🎬 Transition Scripts (Transiciones)

- **`create()`, `update()`, `destroy()`**: El ciclo de vida de la cortinilla negra (u otra animación) que sale al cambiar de pantalla.
- **`onSkip()`**: Si el jugador se salta la transición.
- **`onFinish()`**: Cuando la transición termina de cubrir la pantalla.
